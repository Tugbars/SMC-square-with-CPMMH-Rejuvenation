Robust Prior Calibration for SMC² Filters
in Stochastic Volatility Models

Technical Report
Sequential Monte Carlo Methods for Online Parameter Learning
January 2026
Abstract

Sequential Monte Carlo squared (SMC²) methods enable online Bayesian parameter learning for state-space models, but suffer from a critical cold start problem: misspecified priors can cause filter divergence before learning occurs. We present a three-layer robust calibration framework combining (1) empirical Bayes warmup estimation, (2) historically-informed prior widths spanning calm and crisis regimes, and (3) online convergence diagnostics that detect silent failures. Applied to stochastic volatility models for equity markets, our approach produces priors that adapt to current conditions while maintaining coverage over historical extremes, enabling safe deployment without parameter tuning.

Keywords: SMC², particle filtering, stochastic volatility, prior calibration, regime switching, online learning

Introduction

Stochastic volatility (SV) models are fundamental tools for financial time series analysis, capturing the time-varying nature of market uncertainty. The canonical SV model describes log-returns as:

yt = exp(ht/2) · εt,    ht = μ + ρ(ht-1 - μ) + σzηt
(1)

where ht is the latent log-volatility, ρ controls persistence, and σz governs volatility-of-volatility. The parameters θ = (ρ, σz, μ) are typically unknown and must be estimated.

SMC² (Chopin et al., 2013) provides an elegant solution for online parameter learning: maintain a population of parameter particles, each with an associated particle filter for state estimation. As observations arrive, the parameter posterior is updated sequentially without batch reprocessing.

However, SMC² faces a fundamental challenge we term the cold start problem: the algorithm requires prior distributions over parameters before observing any data, yet misspecified priors can cause catastrophic filter failure before adaptation occurs.

The Cold Start Problem

Why Priors Matter in Sequential Methods

Unlike batch MCMC methods that can explore the posterior through extended sampling, SMC² must initialize particles from the prior and weight them by likelihood. If the prior places negligible mass near the true parameters, the initial particle population will be poorly suited to the data.

Prior-data conflict in SMC². Left: A narrow prior centered away from the true parameter leaves no particles in the high-likelihood region. Right: A wide prior ensures initial coverage of the truth.

The Regime Mismatch Scenario

The problem is particularly acute when market conditions shift. Consider a filter initialized during a calm period (low volatility, high persistence) that suddenly encounters a crisis:

Failure Scenario: A filter calibrated on calm 2017 data (realized vol ≈ 7%) with prior σz ~ N(0.05, 0.03) will assign near-zero likelihood to March 2020 dynamics (realized vol ≈ 70%). The effective sample size collapses, and the filter cannot recover.

The fundamental tension is clear: we need informative priors to enable efficient learning, but robust priors to handle regime uncertainty. Our solution decouples these concerns.

Proposed Approach

We propose a three-layer defense against cold start failure:

Three-layer robust calibration framework. Historical analysis provides prior width (coverage), warmup estimation provides prior center (efficiency), and online diagnostics provide trust signals (safety).

Key Insight: Decouple Center and Width

The critical insight is that prior center and prior width serve different purposes:

Component Purpose Source Failure Mode if Wrong
Center Efficient convergence Current data (warmup) Slow learning
Width Regime robustness Historical extremes Filter divergence
Distinct roles of prior center and width in SMC² calibration.

By sourcing the center from current observations and the width from historical analysis, we achieve both efficiency (starting near the truth) and safety (covering possible regime shifts).

Log-Variance Proxy Method

Direct observation of latent volatility ht is impossible. However, from equation (1), we can derive a proxy relationship:

log(yt²) = ht + log(εt²)
(2)

The noise term log(εt²) follows a log-χ²(1) distribution with known moments: mean ≈ -1.27, variance ≈ π²/2. This enables parameter estimation from observable statistics:

Observable statistics from log-squared returns map to parameter estimates (prior center), which combine with historical bounds (prior width) to form calibrated priors.

The mapping exploits known relationships from SV theory. For instance, the variance decomposition Var(log y²) = Var(h) + π²/2 allows estimation of Var(h), which relates to parameters via Var(h) = σz² / (1 - ρ²).

Calibration Algorithm

Algorithm 1: Robust Prior Calibration
  1. Input: Warmup returns {y₁, ..., yn}, historical bounds B
  2. Compute log-variance series: zt = log(yt²)
  3. Estimate statistics: μ̂z = mean(z), σ̂z² = var(z), r̂₁ = ACF₁(z)
  4. Remove noise variance: V̂h = max(σ̂z² - π²/2, 0.1)
  5. Estimate parameters: ρ̂, σ̂z, μ̂ via proxy relationships
  6. Set prior centers: θ̄ = (ρ̂, σ̂z, μ̂)
  7. Set prior widths: σθ = (B.max - B.min) / 4
  8. Output: Prior π(θ) = N(θ̄, diag(σθ²))

Convergence Diagnostics

Even with well-calibrated priors, online monitoring is essential. We track three diagnostic categories:

Convergence diagnostic framework. The filter reports "ready" only when outer stability, inner filter health, and prior alignment criteria are all satisfied.

Critical: Inner Filter Health

A subtle failure mode occurs when outer parameter stability masks inner particle filter degeneracy. The likelihood estimates p(y1:t|θ) depend on inner filter quality—if inner ESS collapses, likelihood estimates become biased, leading to incorrect parameter posteriors that nonetheless appear stable.

Silent Failure: Outer ESS = 200 (looks healthy), parameter drift = 0 (looks converged), but inner ESS = 5 for 80% of particles → biased likelihood → wrong posterior → confident but wrong.

Our diagnostics explicitly track inner filter ESS across the θ-particle population, flagging when a significant fraction falls below threshold. The "ready" signal requires both outer stability and inner health.

Discussion

Stability vs. Accuracy

An important distinction must be emphasized: convergence diagnostics measure stability (has the posterior stopped moving?) not accuracy (is the posterior correct?). A filter can stabilize confidently on wrong parameters if:

  • The model is misspecified
  • Parameters are weakly identified
  • Prior-data conflict resolved toward prior

Ground-truth validation through simulation studies remains essential for verifying accuracy. The diagnostics provide operational safety signals, not statistical guarantees.

Computational Considerations

The calibration and diagnostic framework adds negligible computational overhead:

  • Warmup calibration: O(n) statistics on ~100 observations, one-time cost
  • Convergence tracking: Host-side circular buffers, ~0 GPU overhead
  • Data transfer: Piggybacks on existing adaptive proposal computations

For typical configurations (512 θ-particles, 256 inner particles), the diagnostic update adds approximately 0.6 μs amortized per observation when checked every 50 timesteps.

Conclusion

We have presented a robust prior calibration framework for SMC² filters that addresses the cold start problem through three complementary mechanisms: historically-informed prior widths ensuring regime coverage, empirical Bayes warmup estimation providing adaptive centering, and online convergence diagnostics detecting silent failures.

The key insight—decoupling prior center (from current data) and prior width (from historical analysis)—enables both efficient learning and robust coverage. Applied to stochastic volatility models for equity markets, the framework enables safe deployment without manual parameter tuning.

For practitioners, we recommend: (1) conduct historical regime analysis for your asset class to establish bounds, (2) implement warmup calibration before filter initialization, (3) monitor convergence diagnostics and defer trading decisions until "ready" status is achieved. This three-layer defense provides meaningful protection against the prior specification challenge inherent in sequential Bayesian methods.
